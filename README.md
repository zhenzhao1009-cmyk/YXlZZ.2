# 我们的故事 · 3D 滚动照片墙

当前版本：**V1.0** · [在线访问](https://zhenzhao1009-cmyk.github.io/YXlZZ.2/) · [下载发布包](https://github.com/zhenzhao1009-cmyk/YXlZZ.2/releases/tag/V1.0)

GitHub Pages 从 `main` 分支的根目录部署。发布包保留页面运行所需资源，包含原版 MP3 和 PCM 备用音频，不包含历史备份与试验音频。

当前主分支：102 张照片分三圈展示，第四圈为 27 段视频。视频卡片仅加载封面，点击后在弹窗中播放；切换和关闭时停止视频，按打开前的状态恢复背景音乐。视频同时提供 H.264/AAC MP4 与 VP8/Opus WebM，按浏览器解码能力选择，播放失败时自动尝试另一种格式，并支持边加载边播放。`videos` 配置项填写 `type: "video"`、`src`、`poster`、`cap` 和 `message`。

一个纯前端（HTML + CSS + JS，零依赖、无需构建）的俯视 3D 环绕照片墙，
用来把你们的照片串成一圈光，送给喜欢的人。


中央嵌入原有粒子玫瑰：点击开场后，粒子从全屏聚拢并绽放，透明背景与照片墙融合；单独打开 `rose.html` 仍可查看完整玫瑰页面。

打开 `index.html` 就能看，但**建议用本地服务器打开**（原因见最后一节）。

## 一、最快上手（3 步）

### 1. 放照片
把你的照片复制进 `images/` 文件夹。

### 2. 改文案
用记事本 / VS Code 打开 **`js/config.js`**，这是唯一需要改的文件：

```js
photos: [
  { src: "images/photo-01.jpg", cap: "第一次见面" },
  { src: "images/photo-02.jpg", cap: "你笑起来的样子" },
  // …想放几张就写几张
],
```

- `src`：照片路径（`images/` 里放了什么就写什么）
- `cap`：鼠标移到照片上显示的一句话
- 张数随意，**8~20 张**效果最好

### 3. 改标题
同一个文件里：

```js
title:    "我们的故事",       // 大标题
subtitle: "把每一个瞬间，都串成一圈光",
note:     "从遇见你的那天起，时间就有了温柔的形状。",
sign:     "— 送给最好的你",
```

保存，刷新页面 —— 完成。

两周年开场：`intro.kicker` 是小标题，`intro.heading` 是按钮上方的告白，`intro.text` 是按钮文字。`note`、`sign` 是按钮下方的寄语与落款；在 `note` 中用 `\n` 换行。`title`、`subtitle` 是可选的照片墙标题，默认留空。每张照片的 `cap` 是回忆标题，`message` 是点击放大后显示的小情话。留空 `message`、`note` 或 `sign` 可隐藏对应段落。

## 三、能做什么

| 操作 | 效果 |
|---|---|
| 按住拖动 / 单指滑动 | 左右旋转照片墙，上下改变俯视角度，松手有惯性 |
| 滚轮 / 双指捏合 | 拉近、拉远照片墙，最远可缩到初始视图的 40% 大小 |
| Shift + 拖动 / 双指同向移动 | 平移整个场景，把屏幕边缘的照片移回视野 |
| Shift + 方向键 | 平移整个场景 |
| ← → / ↑ ↓ 方向键 | 左右旋转 / 调整俯视角度 |
| + / - | 拉近 / 拉远 |
| 复位按钮 / R | 平滑回到初始角度、观看距离和场景位置 |
| 点击照片 | 放大查看，可左右切换 |
| Esc | 关闭大图 |
| 空格 | 暂停 / 继续自动旋转 |
| F | 全屏 |
| 右下角按钮 | 自动旋转 / 复位 / 音乐 / 全屏 |

自动旋转独立持续运行，拖动、缩放、松手惯性、相机复位及查看大图时均不会打断；暂停按钮仍可手动控制。上下视角支持 -72° 到 +72°，可以越过正面继续拖到仰视；平移与缩放也设有边界，避免把场景拖出视野或贴近穿过照片。接近正面时，前景照片会自然遮挡圆心，可继续上下转动视角或缩小查看。中央玫瑰始终朝向镜头。

四排回忆独立持续旋转：第一、三排顺时针，第二、四排逆时针；后方照片形成弧线，前方照片自然放大。照片正反两面均可查看，无底部倒影。系统开启“减少动态效果”时，不自动旋转。

## 四、常见调整

氛围采用紫红暗底、中央柔光和从屏幕顶部持续落下的花瓣雨（默认 72 片，手机最多 36 片）；在 `js/config.js` 的 `atmosphere.petals` 中调整花瓣数量，设为 `0` 关闭。手机自动减少花瓣，系统“减少动态效果”开启时显示静态花瓣。


全部在 `js/config.js` 里。

### 关掉自动旋转
```js
scene: { autoRotate: false }
```

### 转快一点 / 慢一点
```js
autoSpeed: 0.055,   // 越大越快，0.03 很慢，0.12 较快
```

### 调整照片密度与俯视角度
```js
layout: { rows: 4, perRow: 34, rowGap: 1.10, cardFill: 0.76, cardAspect: 1.28 },
scene: { tilt: -23.5, cameraDistance: 1.95, autoRotate: true, autoSpeed: 0.075 },
```
`perRow` 越大，每张照片越小；`cardFill` 越小，照片间的黑色间隙越宽。
`tilt` 控制俯视角度，`cameraDistance` 越小，前景照片越大。
顶部文字默认隐藏，在 `title` 和 `subtitle` 中填写内容即可显示。

### 换背景音乐
把 mp3 放进 `audio/`，然后：
```js
music: "audio/你的歌.mp3",
musicVolume: 0.55,
```
不想放音乐就设成 `music: ""`。

当前使用原版《告白气球》MP3。浏览器不支持 MP3 解码时，`musicFallback` 指定的 16 位立体声 PCM WAV 会通过 Web Audio 播放，仍由原来的音乐按钮控制。备用文件约 41 MB，仅在需要时加载。换歌时请同时替换备用 WAV，或把 `musicFallback` 设为空字符串，避免播放到上一首歌。

> 手机/浏览器默认禁止自动播放，所以音乐会在**用户第一次点击页面后**才开始。

### 关掉飘浮爱心
```js
showHearts: false,
particleCount: 60,   // 星星数量，0 可全关
```

### 改配色
编辑 `css/style.css` 顶部的 `:root`：

```css
--bg:    #07040f;   /* 背景底色 */
--pink:  #ff6fa5;   /* 主色（爱心、光晕） */
--violet:#a97bff;   /* 辅色 */
--gold:  #ffd9a0;   /* 点缀色 */
```

## 五、为什么建议用本地服务器

直接双击 `index.html` 用 `file://` 打开时，Chrome / Edge 出于安全限制
**可能不加载 `audio/bgm.mp3`**（音乐按钮点了没声音）。照片是本地图片，不受影响。

解决办法（任选一个）：

**① 双击 `打开网页.bat`** —— 会自动起一个小服务器并打开浏览器（推荐，需电脑装了 Python）。

**② 用 VS Code 的 Live Server 插件** —— 右键 `index.html` → Open with Live Server。

**③ 命令行**（在项目目录里执行）：
```bash
python -m http.server 8000
```
然后浏览器访问 `http://localhost:8000`。

## 六、发给她看（手机上打开）

### 方案 A：GitHub Pages（免费、长期有效，推荐）
1. 注册 GitHub，新建仓库（Public）
2. 把整个文件夹里的文件上传（`images/`、`css/`、`js/`、`audio/`、`index.html`）
3. 仓库 Settings → Pages → Source 选 `main` 分支 / root → Save
4. 等 1 分钟，得到类似 `https://你的名字.github.io/仓库名/` 的网址，发给她

> 注意：照片是私人内容，Public 仓库任何人都能访问。介意的话用方案 B。

### 方案 B：打包发给她，让她本地打开
1. 把整个文件夹压缩成 zip 发过去
2. 她解压后双击 `index.html`（照片和动效都正常，只是音乐可能不播）

### 方案 C：Vercel / Netlify 拖拽部署
把文件夹直接拖到 [vercel.com](https://vercel.com) 或 [netlify.com](https://app.netlify.com/drop) 的部署区，
几秒后得到网址，同样免费。可设置访问密码。

## 七、照片准备建议

- **比例**：竖图（3:4）最贴合卡片，方图也可以；横图会被裁切中间部分
- **尺寸**：短边 800~1200px 足够，太大只会让加载变慢
- **体积**：单张压到 300KB 以内，20 张总共 5MB 左右比较理想
- **命名**：`photo-01.jpg`、`photo-02.jpg` …… 和 `config.js` 里对应

批量压缩可以用 [squoosh.app](https://squoosh.app)（在线，免费）。
